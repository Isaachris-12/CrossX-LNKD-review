# Platform icons

These nine files are placeholders (solid color swatches, generated by
`apps/mobile/scripts/generate-placeholder-icons.mjs`) standing in for each
platform's real logo. `PlatformIcon.tsx` renders whichever file is here, so
swapping these for the real thing needs **no code changes** - just replace
the file, keeping the exact same filename.

Get the real assets from each platform's official brand kit (using the
brand mark under their guidelines - don't recolor/distort it, and don't use
it in a way that implies partnership or endorsement):

| File | Platform | Brand kit |
|---|---|---|
| `instagram.png` | Instagram | https://about.meta.com/brand/resources/ |
| `facebook.png` | Facebook | https://about.meta.com/brand/resources/ |
| `tiktok.png` | TikTok | https://developers.tiktok.com/doc/login-kit-brand-guidelines |
| `linkedin.png` | LinkedIn | https://brand.linkedin.com/ |
| `youtube.png` | YouTube | https://www.youtube.com/howyoutubeworks/resources/brand-resources/ |
| `reddit.png` | Reddit | https://www.redditinc.com/brand |
| `bluesky.png` | Bluesky | https://bsky.social/about/brand |
| `pinterest.png` | Pinterest | https://business.pinterest.com/en/brand-guidelines/ |
| `mastodon.png` | Mastodon | https://joinmastodon.org/branding |

Any square PNG (or JPG - update the `require()` extension in
`PlatformIcon.tsx` if so) works; `PlatformIcon` renders it in a circular
mask at whatever size the screen requests, so a square logo with reasonable
padding looks best. 128x128 or larger is plenty for how small these render.
